# AI-Generated Text Detection

A web application that classifies text as **human-written** or **AI-generated** using a fine-tuned DistilBERT model.

## Features

- Classifies text as Human or AI-generated
- Displays prediction confidence
- Simple text input interface
- Loading state during prediction
- Input validation
- Error handling
- Responsive web interface

## Machine Learning

The classifier was built by fine-tuning the pretrained:

**`distilbert/distilbert-base-uncased`**

on the **MDAIGT** dataset containing human-written and machine-generated text from news and academic domains.

### Training Pipeline

```text
MDAIGT Dataset
      ↓
Data Cleaning
      ↓
Duplicate Removal
      ↓
Train / Validation / Test Split
      ↓
Tokenization
      ↓
DistilBERT
      ↓
Fine-Tuning with PyTorch
      ↓
Evaluation
      ↓
Saved Fine-Tuned Model
```

### Dataset Split

Total: 19,983 samples

Training:   15,986
Validation:  1,998
Test:        1,999
```

### Test Performance

| Metric | Score |
|---|---:|
| Accuracy | 98.70% |
| Precision | 97.47% |
| Recall | 100.00% |
| F1 Score | 98.72% |

The final evaluation was performed on a held-out test set of 1,999 samples.

## Running Locally

### 1. Clone the repository

```bash
git clone https://github.com/Sid8290/ai-text-detection.git
cd ai-text-detection
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

#### Windows PowerShell

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Make sure the trained model is available locally

The Flask application loads the fine-tuned model from the local `model/` directory.

Place the trained model files in:

```text
model/
```

### 6. Start the application

```bash
python app.py
```

### 7. Open the application

Open:

```text
http://127.0.0.1:5000
```

## Model Output

For each input, the application returns:

- Predicted class
- Confidence score
- Probability for Human
- Probability for AI

## Limitations

The model is trained on the MDAIGT dataset and its performance may differ on text from unseen domains, writing styles, AI systems, or heavily edited content.

Therefore, the prediction should be treated as a **model-based estimate**, not definitive proof that a text was or was not generated by AI.
