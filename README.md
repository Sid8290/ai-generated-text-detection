# AI-Generated Text Detection

A web application that classifies text as Human-written or AI-generated using a fine-tuned DistilBERT model.

## Features

- Classifies text as Human or AI-generated
- Displays prediction confidence
- Text input and analysis
- Loading state during prediction
- Input validation
- Error handling
- Responsive web interface

## Machine Learning

The classifier was created by fine-tuning the pretrained distilbert/distilbert-base-uncased model on the MDAIGT dataset.

### Training Pipeline

MDAIGT Dataset
→ Data Cleaning
→ Duplicate Removal
→ Train / Validation / Test Split
→ Tokenization
→ DistilBERT
→ Fine-Tuning with PyTorch
→ Evaluation
→ Saved Fine-Tuned Model

### Dataset

The dataset contains human-written and machine-generated text from news and academic domains.

After cleaning and removing duplicate text:

Total Samples: 19,983

Training Samples: 15,986

Validation Samples: 1,998

Test Samples: 1,999

### Test Performance

Accuracy: 98.70%

Precision: 97.47%

Recall: 100.00%

F1 Score: 98.72%

The final evaluation was performed on a held-out test set of 1,999 samples.

## Running Locally

1. Clone the repository:

git clone https://github.com/Sid8290/ai-text-detection.git

2. Open the project directory:

cd ai-text-detection

3. Create a virtual environment:

python -m venv .venv

4. Activate the virtual environment on Windows PowerShell:

.\.venv\Scripts\Activate.ps1

5. Install the required packages:

pip install -r requirements.txt

6. Place the trained model files in the local model directory used by the application.

7. Start the Flask application:

python app.py

8. Open the application in your browser:

http://127.0.0.1:5000

## Model Output

For each input text, the application provides:

- Predicted class
- Confidence score
- Probability of Human-written text
- Probability of AI-generated text

## Limitations

The model was trained on the MDAIGT dataset and its performance may differ on text from unseen domains, writing styles, AI systems, or heavily edited content.

The prediction should therefore be treated as a model-based estimate and not as definitive proof that a text was or was not generated by AI.
